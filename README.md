# Daily Task

과목별로 하루 분량을 정해 두고 매일 끝내는 폰용 앱(PWA)입니다. 빼먹으면 벌칙이 있습니다.

지금 들어 있는 과목은 **한국사**(교과서 76~151쪽, 소주제 23개)입니다. 하루 2개씩 하면 12일이면 범위를 한 바퀴 돕니다. 124~127쪽은 원본 파일에 없어서 빠져 있습니다.

## 화면

- **오늘**: 오늘 해야 할 분량을 체크리스트로 보여 줍니다. 항목을 누르면 교과서 페이지가 열리고, 다 읽으면 **다 읽었어요**를 누릅니다.
- **기록**: 달력에 다 한 날, 일부만 한 날, 빠진 날을 표시합니다. 연속 일수와 과목별 진도도 여기 있습니다.
- **과목**: 하루 분량(1~3개)을 정하고, 전체 일정을 봅니다. 하루 분량은 시작하기 전에만 바꿀 수 있습니다.

## 벌칙 규칙

- 과목을 처음 완료한 날이 그 과목의 시작일입니다. 그날부터 하루에 Day 1개씩 끝내야 합니다.
- 하루를 빼먹으면 다음 세 가지가 걸립니다.
  1. 연속 기록이 0일로 초기화됩니다.
  2. 마지막으로 끝낸 Day를 다시 읽어야(벌칙 복습) 밀린 분량이 열립니다.
  3. 밀린 분량과 오늘 분량을 그날 다 해야 합니다.

## 폰에 설치하기

1. 이 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 두고 Save를 누릅니다.
2. 1~2분 뒤 `https://jobaek9.github.io/daily-task/` 주소가 생깁니다.
3. 폰에서 그 주소를 엽니다.
   - **안드로이드(크롬)**: 메뉴 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
   - **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**
4. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열립니다. 처음 한 번 열면 교과서 페이지까지 폰에 저장돼서 인터넷 없이도 볼 수 있습니다.

진도는 폰의 브라우저 저장소에 저장됩니다. 브라우저 데이터를 지우면 진도도 지워집니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 첫 화면 (`page.html`을 `python3 build.py`로 감싸서 생성) |
| `data.js` | 과목 목록 — 과목 추가는 여기서 |
| `app.js` | 화면, 진도 계산, 벌칙 규칙 |
| `app.css` | 스타일 (Tailwind로 미리 빌드) |
| `sw.js` | 오프라인 저장 (서비스 워커) |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 이름과 아이콘 |
| `vendor/` | React, htm (인터넷 없이도 돌도록 같이 넣음) |
| `p/` | 한국사 교과서 페이지 이미지 (`076.jpg` = 76쪽) |

## 과목 추가하기

`data.js`의 `SUBJECTS` 배열에 과목을 하나 더 넣으면 오늘·기록·과목 화면에 자동으로 붙습니다.

```js
{
  id: 'english',            // 영문 아이디 (진도 저장 키)
  name: '영어',
  desc: '[교재 이름]',
  unit: '지문',             // "지문 2개 읽기"처럼 표시됨
  perDay: 2,
  img: (p) => 'en/' + p + '.jpg',
  items: [
    { g: '1', tag: '1강', t: '지문 제목', pages: [1, 2] },
    // ...
  ],
}
```

내용을 바꾼 뒤에는 `sw.js`의 `VERSION`을 하나 올려야(`'v3'` 등) 폰에 새 버전이 받아집니다.
