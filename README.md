# Daily Task

과목별로 하루 분량을 정해 두고 매일 끝내는 안드로이드 앱. 빼먹으면 벌칙이 있다.

지금 들어 있는 과목은 **한국사**(교과서 76~151쪽, 소주제 23개). 하루 2개씩 12일이면 한 바퀴. 124~127쪽은 원본 파일에 없어서 빠져 있다.

## APK 받기

`main` 브랜치에 올라올 때마다 GitHub Actions가 APK를 만들어서 **Releases**에 올린다.
폰에서 저장소의 Releases → 최신 버전 → `daily-task.apk`를 받아서 설치.
항상 같은 키로 서명하므로 새 버전을 덮어 설치해도 진도가 남는다.

> 앱을 **삭제**하면 폰에 저장된 진도도 같이 지워진다. 업데이트는 삭제 없이 덮어 설치.

## 화면

- **오늘**: 오늘 할 분량 체크리스트. 누르면 교과서 페이지가 열리고, 다 읽으면 **다 읽었어요**.
- **기록**: 달력에 다 한 날 / 일부만 한 날 / 빠진 날. 연속 일수, 과목별 진도.
- **과목**: 하루 분량(1~3개) 고르기, 전체 일정. 하루 분량은 시작 전에만 바꿀 수 있다.

## 벌칙 규칙

- 과목을 처음 완료한 날이 시작일. 그날부터 하루에 Day 1개씩.
- 하루를 빼먹으면
  1. 연속 기록이 0일로 초기화
  2. 마지막으로 끝낸 Day를 다시 읽어야(벌칙 복습) 밀린 분량이 열림
  3. 밀린 분량과 오늘 분량을 그날 다 해야 함

## 구조

- `web/` 화면 (React + htm, 미리 빌드한 Tailwind CSS). 진도는 폰 안(localStorage)에 저장
  - `data.js` 과목 목록 — 과목 추가는 여기서
  - `app.js` 화면, 진도 계산, 벌칙 규칙
  - `p/` 한국사 교과서 페이지 이미지 (`076.jpg` = 76쪽)
- `android/` 안드로이드 앱 껍데기 (Capacitor)
- `.github/workflows/build-apk.yml` APK 자동 빌드

## 과목 추가

`web/data.js`의 `SUBJECTS` 배열에 하나 더 넣으면 오늘·기록·과목 화면에 자동으로 붙는다.

```js
{
  id: 'english',            // 영문 아이디 (진도 저장 키)
  name: '영어',
  desc: '[교재 이름]',
  unit: '지문',             // "지문 2개 읽기"처럼 표시
  perDay: 2,
  img: (p) => 'en/' + p + '.jpg',
  items: [
    { g: '1', tag: '1강', t: '지문 제목', pages: [1, 2] },
  ],
}
```
