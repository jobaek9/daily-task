# 교과서 보기

교과서 페이지를 소주제별로 보고, 본 쪽에 **봄** 표시를 하는 안드로이드 앱.

지금 들어 있는 과목은 **한국사**(교과서 76~151쪽, 소주제 23개). 124~127쪽은 원본 파일에 없어서 빠져 있다.

## APK 받기

`main` 브랜치에 올라올 때마다 GitHub Actions가 APK를 만들어서 **Releases**에 올린다.
폰에서 저장소의 Releases → 최신 버전 → `daily-task.apk`를 받아서 설치.
항상 같은 키로 서명하므로 새 버전을 덮어 설치하면 된다.

> 앱을 **삭제**하면 폰에 저장된 '봄' 표시도 같이 지워진다. 업데이트는 삭제 없이 덮어 설치.

## 사용법

- **목록**: 단원별 소주제. 다 본 소주제는 체크, 일부만 본 소주제는 몇 쪽 봤는지 표시. 맨 위에 전체 몇 쪽 봤는지.
- **이어서 보기**: 마지막으로 보던 쪽에서 다시 시작.
- **교과서 화면**: 쪽마다 아래 **봄 표시** 버튼을 누르면 '봄'으로 바뀜(다시 누르면 취소). 맨 아래 **이 소주제 전부 봄**. 페이지를 누르면 크게 보기.

## 구조

- `web/` 화면 (React + htm, 미리 빌드한 Tailwind CSS). 기록은 폰 안(localStorage)에 저장
  - `data.js` 과목·소주제·쪽 목록 — 과목 추가는 여기서
  - `app.js` 화면
  - `p/` 한국사 교과서 페이지 이미지 (`076.jpg` = 76쪽)
- `android/` 안드로이드 앱 껍데기 (Capacitor)
- `.github/workflows/build-apk.yml` APK 자동 빌드

## 과목 추가

`web/data.js`의 `SUBJECTS` 배열에 하나 더 넣으면 목록 위에 과목 버튼이 생긴다.

```js
{
  id: 'english',
  name: '영어',
  desc: '[교재 이름]',
  img: (p) => 'en/' + p + '.jpg',
  items: [
    { g: '1', tag: '1강', t: '지문 제목', pages: [1, 2] },
  ],
}
```
